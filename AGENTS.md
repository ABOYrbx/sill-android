# Agent instructions for this repository

This repository is a fork of the Sill project, hosted at:

- **Origin (this repo):** https://github.com/ABOYrbx/sill-android.git

## Commit identity

- Commits must use the GitHub username **ABOYrbx** as the author name (never the real name), with email `ABOYrbx@users.noreply.github.com`. Set via `git config user.name "ABOYrbx"` and `git config user.email "ABOYrbx@users.noreply.github.com"`.

## Commit / push policy

- All commits and pushes go **only** to `https://github.com/ABOYrbx/sill-android.git` (origin).
- **Never** push, open pull requests, or make any changes to the original upstream project (`Saffsanity/sill` or any other repository). This repository is independent; treat the upstream as read-only reference material.
- Before pushing, verify the remote with `git remote -v` and confirm it points at `https://github.com/ABOYrbx/sill-android.git`.
- If a remote other than `origin` (pointing at ABOYrbx/sill-android) is present, do not push to it.
- Default branch is `main`. Work on feature branches and merge via pull requests into `main` on origin only.
